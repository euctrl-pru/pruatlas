# NM FIRs for AIRAC 524.

A dataset containing the definition of the FIRs as used by the [Network
Manager](http://ansperformance.eu/references/acronym/nm-cfmu.md).

## Usage

``` r
firs_nm_524
```

## Format

A Simple Feature dataset with 111 FIRs and 9 variables:

- airac_cfmu:

  the AIRAC cycle number in CFMU format

- icao:

  the ICAO region code for the FIR

- id:

  the ID for the FIR

- min_fl:

  the minimum flight level of the FIR

- max_fl:

  the maximum flight level of the FIR

- name:

  the name of the FIR

- airspace_type:

  the type of the airspace (FIR)

- geometry:

  the Simple Feature describing the FIR
